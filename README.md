# Showreel

A 30-second motion graphics showreel for Sayan Gupta, Lead Product Manager for AI products.

**Watch with sound:** https://sayanpersonal123.github.io/showreel/ &nbsp;|&nbsp; [Download the MP4](showreel.mp4)

![Showreel end card](poster.jpg)

- One self-contained HTML file. No build step, no video assets, fonts embedded.
- Every frame is a pure function of time, so the browser version and the MP4 match frame for frame.
- The soundtrack (120 BPM, F minor) is synthesized live with the Web Audio API. Kicks, bass, arps, risers and UI blips are scheduled on the same beat grid that drives the cuts.
- The MP4 was exported by rendering 900 frames headlessly and rendering the same score through an OfflineAudioContext.
- Type: Archivo (variable width and weight, animated continuously) and Instrument Serif Italic.

Built with Claude.
